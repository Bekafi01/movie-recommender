# Raw Data Directory

Place the following 5 CSV files from [The Movies Dataset (Kaggle)](https://www.kaggle.com/datasets/rounakbanik/the-movies-dataset) into this directory:

1. `movies_metadata.csv` (~34 MB)
2. `ratings_small.csv` (~2.4 MB)
3. `credits.csv` (~189 MB)
4. `keywords.csv` (~25 MB)
5. `links_small.csv` (~135 KB)

> Note: All CSV files in this directory are git-ignored to keep the repository lightweight.
